## Some Work

**[ResLit](https://github.com/rgsuhas/reslit)**: Got tired of hand-tailoring my resume for every job posting, so now an LLM (bring your own key, pick your own model) does it and spits out a LaTeX PDF. React + Tailwind, FastAPI.

**[shr8 / LinkShrink](https://github.com/rgsuhas/shr8)**: A URL shortener, was reading a few blogs on sys design and thought I should implement this — QR codes, click analytics, rate limiting. Next.js 14, PlanetScale MySQL, Drizzle, Upstash Redis, NextAuth.

**[RAGX](https://github.com/rgsuhas/ragx)**: Everyone ships RAG and prays. This one actually checks its own homework — ingestion through synthesis, streamed, with relevance/faithfulness eval so it can't quietly lie to you.
